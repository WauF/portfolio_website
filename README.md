# Ahmet Emre Kurt — Portfolio

Personal portfolio for Ahmet Emre Kurt, built with Next.js. The optional
vinext scripts target Cloudflare deployments.

## Development

```bash
npm install
npm run dev
```

Use `npm run build` to create the production build.

## Vercel

Import the repository using Vercel's **Next.js** framework preset. Keep the
build command and output directory at their defaults (`next build` and
`.next`).

The `*:cloudflare` scripts use vinext and are not intended for Vercel.
